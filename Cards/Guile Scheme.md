Q: Function to print a string to stdout.
A: `display`

---

Q: True constant.
A: `#t`

---

Q: False constant.
A: `#f`

---

Q: Define a variable `v` with an initial value `e`.
A: `(define v e)`

---

Q: Function to concatenate strings.
A: `string-append`

---

Q: Define a function `square` that returns the square of its input.
A:
```
(define (square x)
  (* x x))
```
